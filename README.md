# BTP 360 — Canal Officiel de Distribution et Mises à Jour

> **BTP 360** — Tous vos chantiers. Un seul pilotage.  
> **كل ورشاتك وصفقاتك تحت السيطرة**

Ce repository public héberge le flux officiel de distribution, les installateurs Windows et les métadonnées de mise à jour automatique (`electron-updater`) pour le logiciel **BTP 360**.

---

## 📥 Téléchargement

Pour télécharger la dernière version de **BTP 360**, rendez-vous sur la section [Releases](https://github.com/wellotek/btp360-update/releases).

- **Installateur Windows (.exe)** : `BTP360-Setup-1.0.0.exe`
- **Fichier de métadonnées** : `latest.yml`
- **Empreinte différentielle** : `BTP360-Setup-1.0.0.exe.blockmap`

---

## 🔄 Mécanisme d'Auto-Update

L'application de bureau BTP 360 interroge périodiquement ce repository pour détecter l'apparition de nouvelles versions publiées dans les releases GitHub. Lorsque disponible, le téléchargement en tâche de fond et l'installation transparente sont pris en charge.
